## Halaman Landingpage MKT ##

    Deskripsi Project : 
    Aplikasi ini dibangun untuk mendukung operasional yayasan amal sosial kemanausiaan. spesifik dalam membangun ekosistem digital dengan semua stakeholder (Tim Rescue, Relawan donor darah, Tenaga medis, Basarnas/BPBD, lembaga filantropi) dalam penanganan bencana. bertujuan untuk mendukung semua pihak dalam penanggulangan bencana baik prabencana, maupun saat bencana terjadi sampai pasca bencana.

    Arsitektur : 
    Aplikasi dibangun menggunakan Laravel 13.20.0 dan vue js

    TASK : 
    - tetap gunakan Tampilan UI/UX yang modern, elegan dan estetik (UserFriendly)
    - Tampilan mendukung mode dark/light dan Responsive
    - Gunakan warna identitak Orange (soft)
    - Lengkapi halaman landingpage dengan image hero section, Profil Mitra Kemanusiaan Terpadu (MKT), layanan, Mitra, dan Kontak yang dilengkapi lokasi kontor Di Perumahan Insignia Oasis Blok B1-11 No 7(Google maps)
    - Tambahkan fitur multi language (Inggris, Indonesia)
    - Tambahkan fitur login cepat dihalaman form login sesuai role (webmaster, mitra, relawan, donatur, medis)
