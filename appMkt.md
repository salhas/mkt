# App-MKT #
    Deskripsi :
    Aplikasi ini dibangun untuk mendukung operasional yayasan amal sosial kemanausiaan. spesifik dalam menghimpun donasi publik dan menggerakkan para relawan donor darah serta tim rescue dalam penanganan bencana. bertujuan untuk membangun sebuah ekosistem yang mendukung semua pihak dalam penanggulangan bencana baik prabencana, maupun saat bencana terjadi sampai pasca bencana.

    Arsitektur : 
    Aplikasi dibangun menggunakan Laravel 13.20.0 dan vue js

    Fitur Aplikasi :
    - Landing Page 
    - Panel Dashboard :
        - Dashboard
        - Profil MKT
        - Anggota/Relawan
        - Donatur
        - Logistik
        - Finance
            -- Jurnal
            -- Laporan
        - Laporan
            -- General Ladger
            -- Buku Besar
            -- Neraca

    - buatkan Tampilan UI/UX yang modern, elegan dan estetik (UserFriendly)
    - buat schema tabel sesuai menu
    - Tampilan mendukung mode dark/light dan Responsive
    - Gunakan warna identitak Orange (soft)
